# Integral Representation and the Computation of Combinatorial Sums

G. P. Egorychev. American Mathematical Society, 1984.
*Translations of Mathematical Monographs*, volume 59.
Translated by H. H. McFaden; translation edited by Lev J. Leifman.

The book develops methods for evaluating combinatorial sums through
generating functions, contour integrals and multidimensional residues.

This is an unofficial editorial edition. It corrects mathematical errors,
misprints and cross-references, and revises unclear English. Substantial
changes are recorded in the accompanying list of corrections; a small number
of editorial footnotes provide additional explanations and references.
